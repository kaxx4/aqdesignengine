# DNA Batch 01 — visual analysis of 8 reference posters

### 091944e282
- WHAT: "Events Calendar in October 2024" — a dated list of 6 holiday events on rounded pill rows, with a URL CTA bar at the bottom.
- ARCHETYPE: stacked_zones
- READING AXIS: top yellow headline card -> down the pill stack row by row -> bottom CTA bar
- HERO: the yellow rounded headline card with "Events Calendar" — ~22% of canvas
- BASE FIELD: dark/ink (near-black) field behind everything, so every pill glows
- ACCENTS: 6 (yellow, mint green, sky blue, pink, red, white) used as CONTAINER FILLS — each pill is a solid field, type is ink on top
- TYPE TREATMENT: clean-bold
- EYE-CANDY MODE: contain (everything lives inside a pill/capsule); a few 4-point sparkles poke out past the pill edges to break the rigid grid
- DENSITY: medium
- STEAL: split each list row into a two-tone capsule — a short left "date" lozenge in one accent butted against a long right "label" lozenge in a different accent, both inside one outlined pill; rotate the accent pair per row so no two adjacent rows share a color.
- REACHABLE: yes(stacked_zones — needs the two-tone split-pill row variant and a dark base field)

### 10f1b8a978
- WHAT: Carousel slide 02 — "HOW ILLUSTRATION ENHANCES YOUR BRAND" with a blue cartoon hand and doodles.
- ARCHETYPE: giant_type
- READING AXIS: left edge of the headline block -> straight down line by line -> subhead; doodles orbit the top-right
- HERO: the 4-line headline stack — ~40% of canvas
- BASE FIELD: light/cream-white, with hairline rules at very top and bottom
- ACCENTS: 4 (yellow highlight bar, green pill, blue hand, red arrows) — highlight/CONTAINER FILLS behind individual words plus one illustration
- TYPE TREATMENT: editorial-stack
- EYE-CANDY MODE: letterform-integrated (the yellow bar is rotated ~-4° behind one word; a black circle-arrow sits INSIDE the word gap of the last line, replacing a space)
- DENSITY: medium
- STEAL: highlight exactly ONE word per headline line with a different container shape — rotated rectangle bar on line 2, rounded pill on line 4 — and let a doodle occupy the inter-word gap as if it were a glyph.
- REACHABLE: yes(giant_type — needs per-line word-highlight containers and the running header/footer rules)

### 11e7d9a3ff
- WHAT: The word "OVERFLOW" spelled out across 3D keyboard keycaps scattered on graph paper, with UI-object props (mail, code window, cursor, pencil).
- ARCHETYPE: isometric_grid
- READING AXIS: top-left orange "O" -> zigzag down-right across the two keycap rows -> props at the corners
- HERO: the field of 8 lettered keycaps as a single mass — ~45% of canvas
- BASE FIELD: texture/paper — pale blue graph-paper grid
- ACCENTS: 7+ (orange, lilac, violet, green, blue, yellow, cream) as LARGE FIELDS — each keycap face is its own accent, rainbow-rotated
- TYPE TREATMENT: per-letter-styled
- EYE-CANDY MODE: juxtapose (loose props scattered around the letter mass, same extrusion language, no frame)
- DENSITY: board-busy
- STEAL: give every object a fixed-direction extruded shadow (solid ink slab down-right, same offset for all) so a flat SVG scatter reads as a coherent 3D set; letters ride ON objects instead of being set as type.
- REACHABLE: no(needs isometric extrusion primitive + one-letter-per-object distribution + graph-paper texture)

### 17c7de5509
- WHAT: A moodboard grid of 7 different "PORTFOLIO" cover treatments (a reference sheet, not a single poster).
- ARCHETYPE: NEW: contact-sheet-grid (a tiled grid of independent mini-compositions)
- READING AXIS: top-left tile -> reading order left-to-right, row by row -> full-width bottom tile
- HERO: the bottom full-width black "PORTFOLIO" tile — ~20% of canvas
- BASE FIELD: dark/ink overall, individual tiles vary (blue, purple, black, photo)
- ACCENTS: 5+ (pink, lime, blue, purple, yellow) used as TYPE COLOR and per-tile base fields
- TYPE TREATMENT: per-letter-styled (each tile deforms/re-styles the same word differently)
- EYE-CANDY MODE: frame (each tile is edge-to-edge, gutterless; the grid itself is the framing device)
- DENSITY: board-busy
- STEAL: same word, N tiles, each tile a different single-move variation (sticker-collage / puffy / script-outline / stretched / geometric) — one shared caption strip spanning the full width to unify the grid.
- REACHABLE: no(needs a tiled sub-canvas compositor — render N mini-posters into one frame)

---
## Cross-batch observations
- 5 of 8 use a **thick ink outline on every shape**; it is the single most consistent unifier.
- 3 of 8 put type INSIDE or ON objects rather than beside them (keycaps, signage, highlight bars) — the engine currently only sets type as type.
- Only 2 of 8 use a light empty field the way the engine defaults to; saturated and ink full-bleed fields are common and read as more confident.

# THE TASTE ENGINE — governing principle (rebuilt from 0, from the full session arc)

## What the session actually taught (my outputs vs the real reactions)
APPROVED moments — structure-first showcase, faithful isometric recreation, radial geometry — all shared:
  → a COMMITTED, COHERENT design decision made BEFORE styling. One governing idea the whole piece serves.
REJECTED moments — gloss bolt-on, clutter-as-depth, template collapse, dropped-fundamentals — all shared:
  → REACTIVE ADDITION with no governing decision. Accumulating "good things" instead of committing to choices.

## THE CORE PRINCIPLE
TASTE = a committed cascade of intentional decisions, made top-down, that COHERE —
where every element earns its place by serving that commitment.
NOT: accumulation of good things. NOT: randomness across absorbed data. NOT: adding.
Taste is COMMITMENT + COHERENCE + SUBTRACTION.

## THE DECISION CASCADE (every generation runs this IN ORDER — each choice constrains the next)
1. INTENT: what is this piece FOR + what's the ONE feeling? (e.g. "recruit / defiant-fun")
2. ARCHETYPE: pick ONE geometry that serves that intent (radial / diagonal / off-frame / stacked /
   scatter / giant-type / isometric / corner). This sets reading axis + focal. COMMIT. Don't hedge.
3. BASE + PALETTE MOOD: one dominant field + an accent SCHEME (mono-pop / duo / triad) chosen to
   serve intent. Accents PUNCTUATE (functional saturation), never flood.
4. TYPE TREATMENT: ONE approach (clean-bold / serif-accent / sticker-label / per-letter). Not a mix of all.
5. EYE-CANDY DEPLOYMENT MODE: how does decoration serve THIS archetype? (frame / contain / direct /
   juxtapose / letterform). Decoration must do a JOB, not fill.
6. THEN styling + craft layer (below) executes the commitment.

## THE NON-NEGOTIABLE CRAFT LAYER (always on, regardless of archetype — dropped these once, got called out)
- Snarky chips in dead zones (voice + fill)
- Doodles in gaps (star/sparkle/heart, rough or clean)
- Grid alignment: everything snap()'d to 8px (ACC target >0.80)
- Collision audit: MUST pass, no overlaps except whitelisted by-design ones
- Big type: headline fills frame; scale up existing elements before adding filler
- Halftone = seasoning (~0.09 baked in fills, never loudest)
- Measure don't guess: PIL band-scan + element-bottom probe for dead zones
- Metric gate: ACC>0.80, VDR 0.06-0.20, scale>4x, flow>0.7 (reading-axis-aware), targets contrast~.26 ink~.11 sat~.31

## THE TWO TESTS BEFORE SHIPPING (the taste check)
A. COHERENCE: does every element serve the one commitment? If an element is just "nice," CUT it.
B. VARIABILITY: is this archetype/mood a genuine DEPARTURE from the last piece, or the template again?
   Two pieces in a row sharing a skeleton = failure. Force different archetype + reading axis.

## WHAT NOT TO DO (my documented failure modes this session)
- Don't bolt on effects reaching for "richer" (gloss/chrome broke brand).
- Don't confuse clutter/overlap with depth (clean separation + shared light = depth).
- Don't guess pixel fixes (measure).
- Don't collapse to one skeleton (commit to a NEW archetype per piece).
- Don't drop the craft layer when chasing novelty (both, always).
- Don't accumulate — COMMIT and SUBTRACT.

# SELF-AUDIT — my generations vs inspiration (honest gap analysis)

## What's working (keep)
- Type scale now bold, fills frame ✓
- Snarky chips carry voice + fill space ✓
- Brand-native texture (subtle halftone, ink shadows, cut-paper) ✓
- Register variety, audit-clean output, no dead bottoms ✓
- Bento structure (PX_mershe) closest to its ref ✓

## THE THREE SYSTEMIC GAPS (priority order)

### GAP 1 — NO HERO OBJECTS (biggest gap)
Every strong reference has a THING: a photographed or richly-illustrated focal object that anchors the whole piece — headphones (Brewdowner), disco ball + bottle (Classico), mic (Design Flow), guitar/dino/boba (Riize), sneaker (Converse). My pieces are type + abstract shapes + doodles. NO anchor object.
FIX: every "hero" piece needs ONE focal object — a real cut-out photo (treated riso/duotone) OR a richly-built illustration, sized large, overlapping the type. Not a doodle — a THING with detail. Source real AQ photos (kids, dogs, trees, drives, events) and cut them out as heroes.

### GAP 2 — FLAT LAYERING, NOT INTERWOVEN DEPTH
I stack clean strata: bg → type → chips. References WEAVE — objects pass BEHIND and IN FRONT of type, type sits between depth planes, elements overlap across layers. This creates the "collage" richness.
FIX: deliberately place some elements behind the headline and some in front (z-index interleaving). Let a hero object's top go behind the title while its body comes forward. Torn-paper/photo edges overlapping letters.

### GAP 3 — SHAPES ARE DECORATIVE, NOT REPRESENTATIONAL
My Matisse blobs are abstract lozenges = decorative filler. Reference cut-paper shapes are RECOGNIZABLE THINGS (hands playing instruments, faces, objects). That's "designed" vs "random shapes."
FIX: when using cut-paper/Matisse, build actual forms — a hand, a leaf that reads as a leaf, a tree, a face, an instrument. Representational, not abstract. Same effort, far more meaning.

## SECONDARY GAPS
- Bento cards should be IMAGE-FORWARD (hero image dominates, text is accent), not text-forward.
- Missing print GRIT on recreations — heavier texture, misregistration, worn edges (riso authenticity).
- Blobs when used should be BOLD + characterful + overlap type, not parked politely in corners.

## IMPROVEMENT PLAN (sequence)
1. Build a HERO-OBJECT system: real photo cut-outs (riso/duotone treated) as focal anchors, + a small library of representational illustrated objects (tree, dog, hand, sapling, book, mic). [addresses GAP 1 + 3]
2. Build INTERWOVEN-DEPTH helper: place-behind-title / place-in-front conventions, z-index planes, overlap-the-letters. [GAP 2]
3. Rebuild 2-3 pieces WITH hero objects + interwoven depth, audit vs ref again.
4. Make bento image-forward.
5. Add optional heavier grit/riso for recreations.
